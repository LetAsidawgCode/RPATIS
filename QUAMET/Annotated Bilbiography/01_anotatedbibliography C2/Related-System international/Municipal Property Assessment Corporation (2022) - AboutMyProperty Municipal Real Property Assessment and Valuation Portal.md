# AboutMyProperty: Municipal Real Property Assessment and Valuation Portal

**Category:** [[Related System international C2]]

**Municipal Property Assessment Corporation. 2022. AboutMyProperty: Municipal Real Property Assessment and Valuation Portal. Web application. MPAC, Pickering, ON, Canada. https://www.mpac.ca/**

- **Summary:** Deployed by the Municipal Property Assessment Corporation across Ontario, Canada, AboutMyProperty operates as a centralized provincial web portal that provides property owners with digital access to municipal assessment notices, valuation methodologies, and classification records used by local treasuries for tax billing.

- **Relevance:** This international public sector platform demonstrates that establishing a centralized, transparent digital assessment repository eliminates valuation ambiguity and standardizes property classification data across jurisdictions. However, MPAC functions as an independent provincial body operating on a decoupled, batch-delivery model: it transmits finalized assessment rolls to local municipalities only once annually, providing no workflow tracking tools for day-to-day inter-office transactions, newly assessed building permits, or immediate parcel subdivisions processed at local municipal counters. Local municipal treasuries cannot track in-progress valuation reviews or coordinate real-time assessment clearances with the assessment authority. The proposed system adapts MPAC's centralized digital repository model to decentralized Philippine local governments by engineering an event-triggered synchronization pipeline, ensuring that daily assessment request approvals in the Municipal Assessor's Office immediately reflect in the Municipal Treasurer's collection ledgers.
