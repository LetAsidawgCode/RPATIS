# ISO 19152-4:2025: Geographic Information — Land Administration Domain Model (LADM) — Part 4: Valuation Information

**Category:** [[Related Literature international]]

**International Organization for Standardization. 2025. ISO 19152-4:2025: Geographic Information — Land Administration Domain Model (LADM) — Part 4: Valuation Information. International Organization for Standardization, Geneva, Switzerland. https://www.iso.org/standard/81266.html**

- **Summary:** The International Organization for Standardization (2025) published ISO 19152-4, establishing standardized conceptual data models and semantic classes to represent administrative property valuations, valuation units, and transaction records, directly supporting the technical integration of land administration registries with municipal property taxation systems.

- **Relevance:** This international data standard directly justifies the data architecture and relational database schema of the proposed system by providing an internationally recognized specification for linking property characteristics and assessment records with fiscal collection ledgers. While ISO 19152-4 provides formal conceptual data models, it does not supply operational web application workflows or document tracking interfaces tailored to the day-to-day administrative handoffs between municipal assessors and treasurers in developing-country local governments. The proposed system addresses this operational limitation by conducting a needs assessment across benchmark municipalities in Camarines Sur to implement an integrated tracking and synchronization platform that applies standardized property and valuation data classes to automate inter-office workflows.

- **Source Reference(s):**
  - _Clause 5: Conformance and Abstract Test Suite (pp. 6–10):_ Outlines semantic data interoperability requirements between cadastral parcel records, valuation registries, and taxation databases.
  - _Clause 6: Valuation Information Package (pp. 12–28):_ Specifies UML conceptual packages for valuation units, property assessments, sales prices, and tax administration linkages.
