# AboutMyProperty: Municipal Real Property Assessment and Valuation Portal

**Category:** [[Related System international]]

**[Municipal Property Assessment Corporation. 2022. AboutMyProperty: Municipal Real Property Assessment and Valuation Portal. Web application. MPAC, Pickering, ON, Canada. https://www.mpac.ca/]**

- **Summary:** The Municipal Property Assessment Corporation (2022) deploys AboutMyProperty, an official government portal that provides property owners across Ontario with digital access to municipal assessment notices, valuation methodologies, and property classification records used by local municipal treasuries for property taxation.

- **Relevance:** This public sector platform demonstrates how establishing a centralized, digital assessment repository enables property owners to verify valuation data and track assessment adjustments; however, MPAC operates as an independent provincial corporation that only delivers finished assessment rolls to municipalities once annually, offering no real-time workflow tracking for local inter-office transactions, building permit revaluations, or day-to-day document coordination between local assessor and treasurer counters. The proposed system addresses this operational gap by designing a localized, lightweight web platform that synchronizes continuous assessment routing and payment updates directly between municipal offices in real time, eliminating multi-day processing latency.
