# Enhanced Tax Revenue and Collection System (ETRACS): Real Property Assessment and Tax Administration Module

**Category:** [[Related System local]]

**[Rameses Systems Inc. 2022. Enhanced Tax Revenue and Collection System (ETRACS): Real Property Assessment and Tax Administration Module. Web application. Rameses Systems Inc., Cebu City, Philippines. http://etracs.org]**

- **Summary:** Rameses Systems Inc. (2022) develops the Enhanced Tax Revenue and Collection System (ETRACS), an enterprise web-based application deployed across Philippine local government units that integrates real property appraisal encoding, tax declaration issuance, and treasury collection ledgers within a centralized database framework.

- **Relevance:** This enterprise platform validates the core technical approach of the proposed system, demonstrating that directly connecting municipal assessor records to treasury collection ledgers prevents billing discrepancies and manual reconciliation errors; however, ETRACS operates as an installed enterprise suite requiring dedicated local server hardware, lacks real-time document tracking monitors to trace multi-step approval routing between municipal offices and external provincial bodies (such as the Provincial Capitol in Pili), and provides no structured needs assessment framework to reconcile legacy paper records dating back to 1949. The proposed system addresses these gaps by implementing a lightweight, web-based platform with real-time assessment routing monitors, automated tax payment synchronization, and inter-office tracking dashboards tailored specifically for municipal assessor and treasurer staff.
